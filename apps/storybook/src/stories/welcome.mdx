# DailyAlgo Design System

> 데일리 알고 디자인 시스템 가이드입니다.

데일리 알고 디자인 시스템은 데일리 알고 서비스의 디자인 통일성을 위해
만들어졌습니다.

모든 디자인 요소는 Tailwind CSS를 사용하여 스타일을 적용하며, 컴포넌트는 shad/cn ui 기반의 React 컴포넌트를 사용합니다.
